# birthday

A cinematic birthday time capsule. Open `index.html` in a browser, no build step.

**Flow:** countdown → tap the chest → particles form the age → read the letter, make a wish (candle, fireworks, a short tune).

## Customize
- **Name, age, unlock date:** `CONFIG` at the top of `app.js`, plus the visible text in `index.html`.
- **Letter:** the `#letter-dialog` section in `index.html`.

## Preview the countdown
Add `?preview=countdown` to the URL. The countdown runs for 10 seconds, then unlocks.
